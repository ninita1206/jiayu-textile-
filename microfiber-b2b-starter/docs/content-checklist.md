# Content preparation checklist

## Before public launch

- [ ] Replace `YOUR BRAND` everywhere.
- [ ] Replace framework and starter notices.
- [ ] Add approved company contact details.
- [ ] Add approved legal entity and address.
- [ ] Select 10–20 core products.
- [ ] Add verified product specifications.
- [ ] Add owned and approved photographs.
- [ ] Build certificate and report register.
- [ ] Check every report’s product scope and date.
- [ ] Confirm manufacturing and sales entity relationship.
- [ ] Confirm capacity and lead-time definitions.
- [ ] Confirm all customer/publication permissions.
- [ ] Add final privacy and terms pages after legal review.
- [ ] Connect and test email/CRM inquiry delivery.
- [ ] Test spam protection and failure alerts.
- [ ] Test mobile, tablet, and desktop layouts.
- [ ] Verify all downloads and links.
- [ ] Keep preview deployments protected.
- [ ] Keep `NEXT_PUBLIC_SITE_INDEXING=false` until final approval.
- [ ] Set the canonical production URL.
- [ ] Run `pnpm check` successfully.
- [ ] Submit a real test inquiry before launch.
